## What to build

Bring the roster row (`RosterRow.svelte` / `rosterRow.ts`) into alignment with the v2 reference on four related points, per PD-43:

1. **Meter**: rebuild the per-row permission-level meter as 3 literal square segments (filled/unfilled per level), matching the reference's actual technique — not the `■■■`/`■■□`/`■□□` text glyph currently used. First amend ADR-0005, which incorrectly claims v2 "kept this rule unchanged" as a text glyph; the actual v2 mockup renders 3 literal segments (same technique as the distribution bar). Fill color is driven by the row's existing level class, reusing `--ink`/`--ink-2`/`--ink-4`; "off" segments use the new `--segment-off` token.
2. **Escalation sigil bug**: an escalation row currently renders the same sigil (`~`) as a plain level change, making escalations indistinguishable at a glance. Fix it to render `↑` for escalations.
3. **Sigil chip styling**: the sigil (±/·/+/−/~/↑) becomes a fixed-size colored chip (background + ink per diff state) instead of bare colored text with no box.
4. **Escalation row tint**: the escalation row's background switches from the (too-saturated) `--escalation-bg` badge token to the new, subtler `--escalation-row` token.

## Acceptance criteria

- [ ] ADR-0005 is corrected to describe the meter as 3 literal segments in v2, not a text glyph
- [ ] Roster-row meter renders as 3 discrete filled/unfilled squares matching the reference, for all three permission levels
- [ ] An escalation `LevelChange` row's sigil renders `↑`; a non-escalation `LevelChange` row's sigil renders `~`
- [ ] Sigil renders as a colored chip (fixed box, background + ink per diff state) for every diff state, including the idle/"same" state in a legible neutral ink
- [ ] Escalation rows render with the `--escalation-row` background tint, not `--escalation-bg`
- [ ] `rosterRow.test.ts` asserts the escalation-vs-plain sigil glyph distinction
- [ ] `pnpm check` and `pnpm test` pass
- [ ] Verified visually via `pnpm dev`/`pnpm tauri dev` against `.references/new-design/perm-diff-ledger-light.html`
