## What to build

Per ADR-0015, retire `SummaryBar.svelte` and `summaryBar.ts`'s `currentStateStats`/`leftClusterLabel` (the current-state admin/write/read cluster). Rebuild the head bar to show delta-only chips (`+N added`, `−N revoked`, `~N changed`, `↑N escalations`, or a `no change` state when the Run pair has no diff) plus a terse trend line (e.g. "13 days · 486 → 492 grants"), reusing `deltaStats`'s existing logic reshaped into the new chip format. The admin/write/read breakdown is not relocated anywhere in the head bar — it remains available only per-repo-card and per-project-header, as today.

## Acceptance criteria

- [ ] `SummaryBar.svelte` and `summaryBar.ts`'s current-state cluster code are removed
- [ ] Head bar renders delta chips matching the v2 mockup's shape (added/revoked/changed/escalations, plus a no-change state)
- [ ] Head bar shows a trend line (span + total grants before/after) per the v2 design
- [ ] No admin/write/read breakdown appears anywhere in the head bar
- [ ] Repo card and project header admin/write/read distribution bars/counts are unchanged
- [ ] `pnpm check` passes
- [ ] Verified via `pnpm tauri dev` for both a diffed Run pair and a same-Snapshot pair (no-change state)
