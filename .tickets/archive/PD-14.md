## What to build

A "changes only" view toggle that hides unchanged rows/cards (prototype state `1d`) — repos/Principals with no diff markers for the current Run pair disappear from view when enabled. Must handle the case where the Run pair has zero changes anywhere (state `1h`) and the case where "changes only" leaves nothing to show (state `1i`), both without the page looking broken.

## Acceptance criteria

- [ ] A "changes only" toggle hides repo cards with a zero change count, and within an expanded card, hides Principal rows with no diff marker.
- [ ] With the toggle on and a Run pair that has zero changes across the whole workspace, the page shows an explicit no-changes state (`1h`), not an empty/blank page.
- [ ] With the toggle on and a Run pair/filter combination that leaves nothing renderable, shows the empty-result state (`1i`) rather than a broken or blank layout.
- [ ] Toggle works together with escalation highlighting (PD-13) without conflict — e.g. changes-only + escalation-highlighting on together still shows Demotions/Grants/Revokes, just filtered to changed items only.
- [ ] Turning "changes only" off restores the full all-collapsed or as-expanded view exactly as it was before filtering.
