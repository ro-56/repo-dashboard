## What to build

The token layer the whole PermDiff console rests on, plus the first thing rendered in it: the roster row. Establishes ADR-0005's two-channel encoding in code — permission level via shape/weight/position, hue reserved for diff state — and ADR-0006's grant-source column.

Vendor IBM Plex Sans + IBM Plex Mono `woff2` into `static/` and self-host them. The reference pulls these from `fonts.googleapis.com`; PRD §6 forbids any network dependency beyond the Bitbucket API. The exact subsets are already inside the reference bundles (`.references/standalone/*.html`, gzipped in the `__bundler/manifest` script).

Define the token sheet from `.references/standalone/1c Token sheet.html` as `:root` custom properties: surfaces (`--surface` #ffffff, `--surface-raised` #fbfcfd, `--surface-sunken` #f4f6f7, `--canvas` #eef0f2, `--canvas-head` #e6e9ec), rules (`--rule` #dcdfe3, `--rule-row` #eff1f3, `--control-edge` #cfd4d9), the ink ramp (#14181c / #3d464e / #5b656d / #6b757d / #8a949b / #b9c0c6), the 8-step type scale (8.5 / 9 / 10.5 / 11 / 11.5 / 12 / 13 / 15), spacing 2/3/4/6/8/9/12/16, `--row-h` 17, `--card-h` 22, bar heights 31/40/44, state hues (added #10653c, revoked #9e2b20, changed #4b46a8), escalation #9a3b00 on #fdf2e4, tag and notice colours, `--strike` #c98d84, `--radius` 2px.

Then rebuild the roster row against that grid.

## Acceptance criteria

- [ ] IBM Plex Sans and Mono load from `static/`, with no request to `fonts.googleapis.com` or `fonts.gstatic.com` at runtime.
- [ ] Tokens are defined once as CSS custom properties and consumed by name; no component hardcodes a hex value from the token sheet.
- [ ] A roster row renders the grid `± | lvl | access | source | user | since baseline | notes` with: a 3px left gutter in the state hue, the state sigil (`+` / `−` / `~` / `·`), the three-cell meter (`■■■` / `■■□` / `■□□`), the level word at weight 600/500/400 for admin/write/read, the grant source, the principal label, the `from → to` transition, and a tag cluster.
- [ ] The grant-source column reads `direct`, `group`, or `grp:<name>` — three values in one column, never spilling into notes. `—` stays reserved for "no level" on either side of a transition.
- [ ] No hue anywhere encodes a permission level. The pre-existing `.roster-permission` styling and any read/write/admin colour classes are removed, per ADR-0005.
- [ ] An Escalation row carries the amber wash (#fdf2e4), the `↑` glyph after the transition, and an `escalation` / `escalation → admin` tag — unconditionally, with no toggle (ADR-0007).
- [ ] A Revoke row shows the level word struck through and the transition ending in `—`.
- [ ] Roster ordering is admin → write → read, then principal label, then grant source (direct before group).
- [ ] Two Member grants held by the same user in one repo render as visibly distinct rows, distinguished by the source column.

## Out of Scope

- Repo card and project section chrome — PD-16.
- Summary bar, head bar, notice strip — PD-18, PD-19.
- Compact/regular density switch — deferred to the filters epic; build compact (17px) only.
- Any change to the Rust diff engine, normalization or storage.

## Further Notes

The reference generates inline style strings from a `DCLogic` class. Do not port that shape — it is an artifact of the prototyping tool. Use scoped Svelte styles and CSS custom properties.

Design source: the states `1a`–`1i` are one React component driven by a `scene` prop, identical in all eight bundles. Extract it from the gzipped `text/html` entry in any bundle's `__bundler/manifest`.
