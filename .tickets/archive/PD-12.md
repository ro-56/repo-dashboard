## What to build

Render the diff data the Roster tree has carried since PD-10's Rust layer, but the UI ignored until PD-11: per-Principal Grant/Revoke/Level-change markers in the expanded roster, and whole-card strikethrough for a repo absent from one of the two compared Snapshots' discovery (prototype state `1e`). Collapsed-card change counts (already rendering since PD-10) now reflect real, distinct Run pairs rather than always reading zero.

## Acceptance criteria

- [ ] Selecting two distinct Snapshots as a Run pair shows, per Principal row in an expanded card: a Grant marker (new in B), a Revoke marker (present in A only), or a Level-change marker (Escalation vs Demotion, per `read < write < admin`).
- [ ] A repo present in one Snapshot's discovery but absent from the other renders as a struck-through card (state `1e`) for its entire roster, distinct from a repo with zero grants.
- [ ] Collapsed-card change counts match the number of diff markers that would render if the card were expanded.
- [ ] Escalation vs Demotion is visually distinguishable at least by marker type/label (full highlighting toggle is a later ticket).

## Out of Scope

- Escalation-highlighting toggle (visual emphasis beyond basic marker distinction) — next ticket.
- Changes-only filter, empty/no-changes states — final ticket in this sequence.
