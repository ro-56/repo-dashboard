## What to build

The management surface for the **Excluded principal** exclusion set built in PD-91, per PD-90's confirmed design (`.draft/Ledger Light.dc.html`).

- A slim banner appears above the Roster tree only when the exclusion set is non-empty: "N principals hidden this session" (verbatim copy).
- A "Manage" toggle (reads "Hide list" while expanded) reveals a list with one row per excluded Principal, each with its own "Unhide."
- A bulk "Unhide all" action clears the exclusion set entirely.
- Zero footprint when nothing is excluded — no banner, no new chrome.
- This is the *only* surface for viewing/removing exclusions — there is no `FilterBar` popover, funnel icon, or multi-select/autocomplete add control (explicitly out of scope per PD-90).

## Acceptance criteria

- [ ] Banner is absent when the exclusion set is empty.
- [ ] Banner appears with the correct count and pluralization once ≥1 Principal is excluded.
- [ ] "Manage" expands the list and its label flips to "Hide list"; collapsing flips it back.
- [ ] Each excluded Principal appears once in the list (by label), with a working "Unhide" that removes just that one exclusion and un-hides its rows in the tree.
- [ ] "Unhide all" clears every exclusion and collapses/hides the banner.
- [ ] Manually verified via `pnpm tauri dev` (Svelte rendering, no Playwright/component tests per ADR-0017).
