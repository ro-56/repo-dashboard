## What to build

Add `perm-diff.css`'s `:root[data-theme="dark"]` token block to `tokens.css` (ADR-0016). Add a small `theme.ts` module exposing the current theme (`"light" | "dark"`), a setter, and an init read from `localStorage` defaulting to `window.matchMedia("(prefers-color-scheme: dark)")` when no stored preference exists; applies the theme by setting `data-theme` on the root element so the switch is instant and CSS-only. Add a toggle control inside `SideDrawer.svelte` alongside credentials/Run/snapshot management (ADR-0010).

## Acceptance criteria

- [ ] `:root[data-theme="dark"]` block exists in `tokens.css` with `perm-diff.css`'s dark values
- [ ] `theme.ts` persists the user's choice to `localStorage` and reads it back on launch
- [ ] With no stored preference, the app defaults to the OS's `prefers-color-scheme`
- [ ] A toggle in `SideDrawer` switches themes instantly, with no reload, across the whole dashboard
- [ ] No component renders a hardcoded light-only hex value that breaks in dark mode
- [ ] `pnpm check` passes
- [ ] Verified via `pnpm tauri dev`: toggle, relaunch (persistence), and first-launch-with-no-preference (OS default) all behave correctly in both themes
