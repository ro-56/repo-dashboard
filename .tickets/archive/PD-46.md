## What to build

Per PD-43, replace the repo card header's admin/write/read distribution bar's single-gradient-element implementation with 3 literal segments matching the reference (`repoCard.ts` / `RepoCard.svelte`). The current implementation also has a color bug: the "write" segment uses `--ink-3` instead of the correct `--bar-write`.

Replace `distributionBarBackground(repo): string` (returns a hand-built CSS `linear-gradient`) with a function returning per-segment percentages (admin/write/read, summing to 100), or a signal for "no grants" when the repo has zero grants — preserving the existing behavior of a flat neutral bar (not an empty element) in that case. `RepoCard.svelte` renders 3 segments with a 2px gap, colored from `--bar-admin`/`--bar-write`/`--bar-read`.

- [ ] Segment colors match `--bar-admin`/`--bar-write`/`--bar-read` (write segment no longer uses `--ink-3`)
- [ ] A repo with zero grants still renders a single flat neutral bar, not three empty/invisible segments
