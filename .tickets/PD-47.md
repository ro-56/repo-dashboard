## What to build

Per PD-43, every delta count kind in `CountBadges.svelte` (added/removed/modified/escalation/no-change) should render as a filled color chip — matching the visual treatment the head bar's delta chips already use — instead of today's bare colored text (only the escalation kind currently gets a boxed treatment, and it uses the wrong height/radius tokens).
