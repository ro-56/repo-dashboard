## What to build

Replace `tokens.css`'s color, spacing, and type-scale custom property values with the v2 numbers from `.references/new-design/perm-diff.css`'s `:root` block (light theme only — the dark block is a later ticket). Keep this app's existing self-hosted `/fonts/*.woff2` `@font-face` declarations rather than porting `perm-diff.css`'s Google-Fonts-hosted font URLs (PRD §6 forbids runtime CDN calls) — font family names and weights (IBM Plex Sans/Mono 400/500/600) already match; only `src` stays as-is. Every consuming component already resolves color/spacing through these token names (ADR-0005), so most of the app should re-skin automatically. Components with geometry hardcoded outside of `tokens.css` (chrome bar heights, roster/card pixel dimensions) are handled in separate follow-on tickets, not here.

## Acceptance criteria

- [ ] Every color/spacing/type custom property in `tokens.css`'s `:root` block matches the corresponding v2 value in `perm-diff.css`
- [ ] Font-face declarations still point at this app's self-hosted `/fonts/*.woff2` files, not a remote URL
- [ ] No new hardcoded hex/px values introduced in any component as a side effect of this change
- [ ] `pnpm check` passes
- [ ] Verified via `pnpm tauri dev`: overall palette/spacing visibly matches the v2 mockup even though some component-level geometry hasn't been ported yet
