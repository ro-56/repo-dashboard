## What to build

Add the Tauri plugin infrastructure needed for a native \"Save As\" file write, so the CSV export ticket (blocked by this one) has a save mechanism to call into. Pure plumbing — no business logic, no user-facing feature on its own.

- Add \`@tauri-apps/plugin-dialog\` and \`@tauri-apps/plugin-fs\` as dependencies (Rust crate in \`Cargo.toml\`, JS package in \`package.json\`).
- Register both plugins in \`src-tauri/src/lib.rs\`'s Tauri builder.
- Grant the permissions each plugin needs (save-dialog, file write) in \`src-tauri/capabilities/\`.

## Acceptance criteria

- [ ] \`@tauri-apps/plugin-dialog\` and \`@tauri-apps/plugin-fs\` are added and registered.
- [ ] Capabilities config grants exactly the permissions needed (dialog save, fs write) — not a blanket grant.
- [ ] Manually verified via \`pnpm tauri dev\`: a throwaway call to open a native Save As dialog and write a small test file succeeds, then the throwaway call is removed before this ticket is considered done (the real caller lands in the next ticket).
- [ ] \`cargo check\` and \`pnpm check\` both pass.
