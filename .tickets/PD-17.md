## What to build

Everything the console's chrome needs to display that the Roster tree does not currently carry: workspace-wide summary aggregates, and the two structural facts the reference narrates but the current model has no term for until now — repo arrival and workspace departure/arrival.

Computed in Rust, returned alongside the tree from the same command, per ADR-0004's precedent: grouping and counting logic lives where `cargo test` can reach it, not in TypeScript.

## Acceptance criteria

- [ ] The roster-tree command returns, in addition to the tree, a summary describing the Comparison Snapshot: total grants, distinct repos, distinct user Principals, and grant counts per level (admin / write / read).
- [ ] It also returns pair-level stats: added, revoked, changed, escalations, repos hit (repos with at least one change), and net (Comparison grant count minus Baseline grant count, signed).
- [ ] Every count counts `PermissionRecord` rows, not people, per ADR-0008 — a user holding a Direct `read` and a Member `admin` on one repo contributes two grants and one distinct user.
- [ ] Summary figures are always computed over the full Run pair and are never affected by any view or filter state.
- [ ] Each repo node carries its discovery state across the pair: present in both, absent from the Comparison, or arrived in the Comparison — distinct from a repo that was discovered but whose permissions call failed.
- [ ] Each user Principal carries its workspace-wide state: present in both Snapshots, departed (holds grants in the Baseline and none anywhere in the Comparison), or arrived (the reverse). Losing access to one repo while keeping others is not a departure.
- [ ] Selecting the same Snapshot for both sides yields zero for every pair-level stat and no departures or arrivals, rather than an error.
- [ ] `cargo test` covers: the counting rule against a fixture with multiple grant sources per user; net going negative; a repo present in only one side; a user departing; a user departing from one repo but not the workspace; and the same-Snapshot pair.

## Out of Scope

- Rendering any of this — PD-18 and PD-19 consume it.
- Effective (cross-record) permission per user. ADR-0008 deliberately keeps counting at the grant level precisely to avoid un-deferring ADR-0001.
- Any change to collection, storage, normalization or the diff engine itself.
