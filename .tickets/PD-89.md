## What to build

Complete the user-facing round trip for PD-87: let the user actually type a Justification when they stage a permission edit, and see it reflected back to them before and after Apply.

- `RosterRow.svelte`'s edit menu gains an inline free-text input for Justification, shown alongside the level picker / Remove option when staging a `SetLevel` or `Remove` edit against a Direct or Group grant. Typing is optional — leaving it blank stages the edit with no justification, exactly as today. The value is passed straight into the `StagedEdit` object already built by `selectLevel`/`selectRemove` (the `justification` field itself was added to the type in PD-88).
- `ConfirmApplyDialog.svelte` displays the Justification (when present) alongside each row in both the review phase (before the user clicks Confirm) and the results phase (after Apply completes) — reusing the `justification` field already threaded through `ConfirmRow`/`ResultRow` in PD-88.
- Re-opening a row's menu after staging (to change level or Undo) should not lose or garble whatever Justification text was already typed for that staged edit.

## Acceptance criteria

- [ ] Staging a level change or Remove from `RosterRow.svelte`'s menu offers a free-text Justification input; leaving it empty stages the edit with no justification (no validation blocks it).
- [ ] The Confirm Apply dialog's review view shows each staged row's Justification text when one was entered, and shows nothing extra when it wasn't.
- [ ] The Confirm Apply dialog's results view (post-apply) likewise shows the Justification for each result row.
- [ ] A Group grant Remove that cascades to Member grants still takes a single Justification for the whole staged edit (no per-Member-grant justification prompt) — matches ADR-0021's existing scope boundary.
- [ ] Manually verified via `pnpm tauri dev` (per ADR-0017 — no Playwright): stage a Remove and a level change, one with a Justification and one without, confirm, apply, and check both the review and results views render correctly in both light and dark theme.
