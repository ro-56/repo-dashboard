## What to build

PD-41 claimed the head bar (`HeadBar.svelte`/`headBar.ts`) already matched the v2 reference exactly, and PD-43 carried that claim forward as out-of-scope. It's wrong — a line-by-line diff against `perm-diff.css`'s `.head-bar`/`.wordmark`/`.selector`/`.icon-button`/`.span-note`/`.delta-chips`/`.chip` rules (and, for literal computed values, `perm-diff-ledger-light.dc.html` lines 13-37) turned up real mismatches PD-41 didn't catch.

**Implemented**, per ADR-0018:

1. **Run selectors**: kept the native `<select>` (no new dropdown/listbox control, no new interaction/open-state code). Each is now wrapped in a `.selector-panel` div (border, `--r-selector` radius, `--surface-control-alt` background, column layout) holding the existing label span above a now-borderless `<select>`. `.selector-panel:focus-within` applies the reference's active look (`--ink` border, `--surface` background, `font-weight: 500` on the value) — lights up whichever selector the user is actually interacting with, rather than statically favoring comparison the way the static mockup screenshot does. A true custom panel control matching the mockup's exact idle-state active/muted asymmetry is deferred to a future ticket.
2. **Wordmark direction**: `flex-direction: column; gap: var(--s-1)` (was row/baseline-aligned). Brand letter-spacing corrected to `-0.02em` (was `-0.01em`).
3. **Ink tokens**: `.eyebrow` → `--ink-3` (was `--ink-mute`), letter-spacing `.14em` (was `.11em`). `.span-note` → `--ink-4` (was `--ink-mute`); also dropped an incorrect `font-family: var(--font-mono)` — neither `perm-diff.css`'s `.span-note` rule nor the mockup's computed style override font-family there, so it inherits the body's sans font.
4. **Selector geometry**: `.selectors` gap `var(--s-3)` (was `var(--s-6)`); panel `min-width: 150px` (was 196px on the old `.selector`); `.selector-label` font-size `var(--t-label-sm)` (9.5px, new token) and letter-spacing `.12em` (was `--t-tag`/10px and `.09em`).
5. **Swap button**: background `var(--surface)` (was `--surface-sunken`), font-size `var(--t-meta)` (was `--t-body-s`) — matches `perm-diff.css`'s `.icon-button` base rule.
6. **Drawer toggle**: 28x28px (was 26x26), `border-radius: var(--r-card)` (was `--r-selector`), background `var(--surface)` (was `--surface-sunken`) — matches `.icon-button--lg`.
7. **Delta-chips grouping**: added `margin-left: auto` to `.delta-chips` per `perm-diff.css`'s own rule (redundant alongside `.span-note`'s existing `flex: 1 1 auto`, which already produced the same rightward push, but now faithful to the source rule too). `.chip` `align-items` corrected to `center` (was `baseline`), matching `perm-diff.css`'s `.chip` rule.
8. **New tokens** (`tokens.css`): `--surface-control-alt: #fbfcfd` and `--t-label-sm: 9.5px`, both sourced from `perm-diff.css`'s light-theme `:root` block.

**Investigated and deliberately not changed:**
- The escalation chip's bolded caption (`font-weight: 600`) appears only in the mockup's inline computed style, not in `perm-diff.css`'s actual `.chip__label` rule (which is a single generic `font-weight: 500` rule with no escalation modifier). Per PD-43's own established precedent — `perm-diff.css` wins when it disagrees with a mockup's literal/generated inline values — this was left alone rather than added as a one-off, unbacked override.
- Delta-chip `height`/`gap`/`padding`/`border-radius` use `perm-diff.css`'s token values (`--h-control`, `--s-3`, `--s-5`, `--r-chip`), not the mockup's slightly different inline literals (26px/5px/9px/6px) — same precedent, already the case before this ticket.

## Testing Decisions

Same posture as PD-43's sibling tickets (ADR-0017): this is CSS/markup-only against an already-correct `headBar.ts` (no pure-function logic changes), so there's no new automated seam. `pnpm test` (39/39 existing tests) confirms no regression from the token/markup changes.

## Out of Scope

- A custom panel control for the Run selectors (open/close state, listbox, click-outside handling) that would match the reference's exact idle-state active/muted asymmetry — deferred per ADR-0018.
- Dark theme.
- Any diff/permission computation or `headBar.ts` logic changes.
- Escalation chip label bold — investigated, not backed by `perm-diff.css`'s actual rules, left as-is (see above).
